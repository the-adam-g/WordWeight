# WordWeight
A project by Adam gillion
## Preface
My first general purpose programming language was python. In my opinion its probably easier to learn your first language than to learn another language as you experience the syntax with no conflicting knowledge/experience and you work on little projects that might seem silly or useless but it can be the best way to practice the basics and learn the language.

So i produce a pretty simple project i whipped up on a stupid idea. I was trying to remember a name and said a name similar but not exact (I said Stacy instead of Suzi) and defending myself with "Close enough"... and then I realised how could I measure a metric for how close I was. As a result, I made WordWeight.
